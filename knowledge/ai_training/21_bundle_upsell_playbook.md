## 0. Главный принцип

**Лестница строится trust-by-trust, не цена-в-цену.**

Не «сразу T5 чтобы спендил больше». Постепенный rise через trust:
- T1 → T2 (через 3-7 дней warm).
- T2 → T3 (через 5-10 дней + buy-signal).
- T3 → T4 (через 10-21 день + clear whale-signal).
- T4 → T5 (только confirmed whale-status).

Перепрыгнуть = оттолкнуть.

```
T1 ($10-18)   — entry / soft, новички, soft GFE
T2 ($20-35)   — standard mid-PPV, recurring

T4 ($60-90)   — premium-set, status / whale
T5 ($100-200) — VIP-set / large bundle
T6 ($200-700) — custom (см. 12)
```

|---|---|---|
| T1 | D3-D7 | A1, B3, C1, C5 |

| T3 | D7-D21 | A5 repeat, C2, C4, B1 in pipeline |

| T5 | D30+ | Active whale B1 |
| T6 | По inquiry | D1 customizer, whale |

## 2. Triggers для подъёма tier

### 2.1 T1 → T2

✅ Открыл T1 PPV.
✅ Положительная реакция («love it», «more please»).
✅ Warm chat 2+ дня.

### 2.2 T2 → T3

✅ Открыл 2+ T2 PPV в течение 14 дней.
✅ Не торговался.
✅ Mentions wealth markers / профессии с good income.

### 2.3 T3 → T4

✅ Открыл 2+ T3 PPV.
✅ Активно общается + memory premium engaged.
✅ Tips occasional.

### 2.4 T4 → T5

✅ Confirmed whale-status (см. `13`).
✅ 4+ purchases in 30 days.
✅ Spent $300+ in 30 days.

### 2.5 T5 → T6 / T7

✅ Active whale 60+ days.
✅ Mentions custom interest.
✅ Tipping consistently.

### 2.6 Anti-trigger

❌ Любой негативный сигнал → тiering **назад**, не вперёд.
❌ Burnout signal → drop down 2 tiers temporarily.
❌ Refund-conflict → reset до T1 с этим фаном.

## 3. Bundle структуры

### 3.1 Bundle 2-pack (T2)

> 2 PPV в одном offer, скидка 10-15%.

```

если хочется — pack за $40 (вместо $25+$22)
)
```

**Когда:** D7-D14 после первого PPV-purchase.
**Тип фана:** C2, A5.

### 3.2 Bundle 3-pack (T3)

> 3 PPV в одном offer, скидка 15-20%.

```
вышли 3 в осенней гамме за последний месяц)
если хочется все три — pack за $60 (вместо $25+$30+$25)
)
```

**Когда:** M2+ active fan.
**Тип фана:** C2, A5, B2.

### 3.3 Bundle 5-pack (T4)

> 5 сетов, скидка 20-25%.

```
у меня собрано 5 сетов из последнего месяца — studio, GFE, premium mix
если хочется — pack за $150 (вместо $190 если по одному)
)
```

**Когда:** Active whale в pipeline.
**Тип фана:** C4, B1.

### 3.4 Bundle GFE-pack (T3-T4)

> GFE-фокус, для C3 / B1-GFE-whale.

```
у меня вышли вещи в одном тёплом GFE mood — lilac robe, soft morning, intimate evening
если хочется — pack 4 сетов + 2 voice notes за $120
)
```

**Когда:** Confirmed C3 GFE-fan.

### 3.5 Bundle premium / VIP (T5)

> Premium curation — only top sets.

```
у меня собран VIP-pack из лучшего за квартал — 8 сетов + 3 voice + 1 mini-video
если интересно — $300, только для тех кто давно)
```

**Когда:** Whale 30+ days active.

### 3.6 Bundle full VIP (T7)

> Всё-в-одном: контент + custom + voice + premium access.

```

- 10 сетов из последнего 3 месяцев
- 5 voice notes специально к тебе
- 1 custom video по твоему запросу (3 мин)
- priority response в DM

всё за $500/месяц)
```

**Когда:** Active whale 60+ days, multiple T4-T5 buys.

## 6. Когда **НЕ** upsell / bundle

❌ В первой purchase (после T1 → не сразу bundle, дать 7-14 дней).
❌ После refund-conflict (reset до T1).
❌ После crisis disclosure.
❌ После burnout signal whale.
❌ В первое сообщение дня (warmup сначала).
❌ Сразу после большой purchase ($100+, дать 24-48 часов).
❌ В welcome.
❌ В негативной mood-фазу фана.

## 7. Bundle pricing strategies

### 7.1 Discount math (баseline)

| Bundle | Скидка от sum |
|---|---|
| 2-pack | 10-15% |
| 3-pack | 15-20% |
| 5-pack | 20-25% |
| 8+ pack | 25-30% |
| VIP T7 | 30%+ + добавленная ценность (custom, voice, access) |

### 7.2 Anti-discount

❌ Discount чтобы продавить отказ. Если фан сказал «$50 too much» —
не «$50 → $35 special for you». Это разрушает trust.

✅ Discount **только** в формате bundle (несколько items).

### 7.3 Value-add вместо discount

Вместо «скидка 20%» — «+1 voice note free» / «+ bonus кадр» / «priority
ответы».

## 12. Anti-milking правила

> Главный риск bundle / upsell = milking → burnout → churn.

### 12.1 Cooldown между PPV / bundle

| Tier | Min cooldown |
|---|---|
| T1-T2 | 24-48 часов |
| T3 | 48-72 часов |
| T4 | 3-5 дней |
| T5 | 7-14 дней |
| T6 (custom) | 7-14 дней |
| T7 (VIP) | 30 дней + |

### 12.2 Max в неделю

| Тип фана | Max PPV/нед | Max Bundle/нед |
|---|---|---|
| A1 newcomer | 1-2 | 0 |
| Mid-tier | 2-3 | 1 |
| Whale | 2-3 | 1 |
| Vulnerable | 1 | 0 |

### 12.3 Burnout signals → drop tier

См. `13_whale_lifecycle_playbook.md` раздел 9.

## 14. Анти-паттерны bundle / upsell

❌ **Bundle сразу после первой purchase.** Дать 7-14 дней.
❌ **Скакать через tiers** (T1 → T4 за неделю).
❌ **Discount «торг»** на отдельный PPV.
❌ **Bundle когда фан quiet 2+ дня.**
❌ **Multiple bundle offers** в одной неделе.
❌ **VIP T7 для newcomer.** Никогда раньше M3.
❌ **Bundle в crisis / vulnerable conversation.**
❌ **Bundle + tip-prompt в одно сообщение.**
❌ **«Special discount only this week!»** urgency.
❌ **Mass-message VIP T5+.** Personal только.

# DiskCleaner

Полноценное десктопное приложение на Python (PyQt5) для анализа и очистки дискового пространства Windows.

## Возможности

- Вкладка **Карта диска**: анализ структуры папок, сортировка по размеру, проваливание в подпапки, прогресс сканирования.
- Вкладка **Поиск мусора**: поиск мусора по категориям, выбор элементов, удаление или карантин.
- Вкладка **Большие файлы**: поиск файлов больше порога, сортируемая таблица, удаление, открытие папки.
- Вкладка **Дубликаты**: быстрый поиск по размеру + SHA256, группировка копий.
- Вкладка **Старые файлы**: поиск файлов, к которым долго не обращались.
- Боковая панель: выбор диска, инфо о диске, круговая диаграмма, экспорт отчёта, анализ расширений, поиск пустых папок.
- Безопасность: подтверждение перед удалением, уровни риска, лог операций, поддержка карантина.

## Быстрый запуск через терминал

```bash
pip install -r requirements.txt
python main.py
```

Или в Windows:

```bat
install.bat
run.bat
```

## Полный запуск с нуля в PyCharm (Windows)

1. Установите **Python 3.10+** и **PyCharm Community/Professional**.
2. Скачайте/распакуйте проект и откройте в PyCharm папку `DiskCleaner`.
3. Создайте виртуальное окружение:
   - `File` → `Settings` → `Project: DiskCleaner` → `Python Interpreter`.
   - Нажмите `Add Interpreter` → `Add Local Interpreter` → `Virtualenv` → `OK`.
4. Установите зависимости:
   - Откройте `Terminal` в PyCharm и выполните:
     ```bash
     pip install -r requirements.txt
     ```
5. Настройте конфигурацию запуска:
   - `Run` → `Edit Configurations...` → `+` → `Python`.
   - `Name`: `DiskCleaner`.
   - `Script path`: `<путь_к_проекту>\DiskCleaner\main.py`.
   - `Working directory`: `<путь_к_проекту>\DiskCleaner`.
   - `Python interpreter`: ваш venv (созданный на шаге 3).
6. Запустите кнопкой **Run** (зелёный треугольник).

## Запуск от имени администратора (Windows)

Для доступа к части системных директорий лучше запускать PyCharm от администратора:

1. Закройте PyCharm.
2. Нажмите правой кнопкой по ярлыку PyCharm → **Запуск от имени администратора**.
3. Запустите конфигурацию `DiskCleaner`.

Если запускать без админ-прав, приложение всё равно работает, но часть системных папок может быть недоступна.

## Частые проблемы в PyCharm

- **`ModuleNotFoundError: No module named PyQt5`**
  - Проверьте, что выбран правильный интерпретатор (venv) и выполнен `pip install -r requirements.txt`.
- **Окно не открывается / ошибки Qt-плагинов**
  - Обычно помогает пересоздать venv и переустановить зависимости.
- **Нет доступа к системным папкам**
  - Запустите PyCharm от имени администратора.

## Скриншоты интерфейса (описание)

- Главное окно с тёмной темой и вкладками анализа.
- Вкладка "Поиск мусора" с группировкой категорий и чекбоксами.
- Вкладка "Большие файлы" с таблицей и сортировкой.
- Вкладка "Дубликаты" с группами файлов по хешу.

## Важные примечания по безопасности

- Опасные системные категории показываются как **только информация**.
- Удаление выполняется только после подтверждения.
- Все операции удаления логируются в `logs/cleanup_log.txt`.
- Можно включить режим **карантина** вместо физического удаления.


## Логи работы приложения

- Подробный runtime-лог пишется в `logs/app_runtime.log` (старт/завершение сканов, найденные элементы, операции удаления/ошибки).
- Лог операций очистки также сохраняется в `logs/cleanup_log.txt`.

## Права доступа

- При старте без админ-прав приложение спрашивает: **перезапустить с правами администратора** (UAC).
- Если отказаться, программа продолжит работу в ограниченном режиме.
